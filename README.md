# ElMagica

**Build Beta1.0 — Endless Play / Mechanics Test**

Небольшая пиксельная игра про мага, который поднимается по бесконечной башне. Четыре стихии, разные враги, боссы с двумя стихиями и торговец между боями. Чем выше забираешься, тем сложнее становится.

![ElMagica](assets/ui/menu/cover.png)

## Зачем я это делал

Хотел собрать свою игру: чтобы можно было выбрать стихию, попробовать разные атаки, прокачивать персонажа и посмотреть, насколько далеко получится зайти. Началось всё с сетки клеток и квадрата, который умеет двигаться и стрелять. Потом появились враги, боссы, комнаты, магазин, графика и звук.

Делал на Java и LibGDX с серьёзной помощью OpenAI Codex: придумывал механики, тестировал, менял баланс и постепенно разбирался в реализации. Картинки тоже сделаны с помощью ИИ, музыка и эффекты — через скрипт синтеза звука.

Сейчас это рабочая бета для проверки механик. Хочу понять, что интересно играть, где ломается баланс и что стоит развивать дальше.

## Попробовать

Нужна **Java 17+**, рекомендую Java 21. Скачай архив игры из **Releases**, распакуй и запусти `play/Run-ElMagica.bat`. Java в комплект не входит.

**WASD** — движение, **мышь** — прицел, **зажатая ЛКМ** — стрельба, **E** — взаимодействие, **ESC** — пауза. В настройках можно выбрать русский или английский язык. Сохранения забега пока нет.

Для запуска из исходников на Windows:

```powershell
.\gradlew.bat lwjgl3:run
```
